SFG WEBSITE - STEP 19

Website entry point: index.html
Deployment: upload all included files with their folders; keep image/ and cloud/ paths intact.

DELIVERY ORDER GROUPING
- Enter the SAME D.O. No and the SAME Delivery Date for multiple items in a single document.
- Open Delivery Order for any one of those items; all matching items appear together in MANUFACTURED ITEMS.
- A different D.O. No OR a different Delivery Date creates a separate Delivery Order.

ORIGINAL FORMER
- Tick 'Original Former' next to the desired item's Delivery Order button.
- Enter the return Qty in the separate Qty field beside the checkbox.
- The ORIGINAL ITEMS BEING RETURNED table shows '(Original Former) <item name>', same size and side, and the separate Qty (not the manufactured Qty).
- If the checkbox is not selected the row is not listed under returns.

Existing Google Sheets Cloud Sync and Backend are unaffected. No new connection settings required.
